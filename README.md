# WealthPilot (財富領航) — 一條龍個人理財與智慧投資平台

> 一站式整合「固定開銷與收支審視」、「個人真實淨值防護」、「人生財務目標 (FIRE)」、「全球股市即時行情」與「智慧投資建議決策」的現代全端財務平台。

---

## 🌟 核心特色

1. **固定開銷雷達 (Fixed Obligations)**：
   - 獨立審視房貸、車貸、信貸、房租與保費，計算固定負擔比率 (Fixed-to-Income Ratio)。
2. **50/30/20 黃金預算分析**：
   - 即時診斷必要開銷 (50%)、享受娛樂 (30%) 與儲蓄投資 (20%) 水位。
3. **CSV 帳單批次匯入**：
   - 支援台灣各大網銀與信用卡 CSV 帳單匯入，具備台灣在地商戶關鍵字自動歸類與重複過濾防呆。
4. **全球股市即時公開行情連線**：
   - 整合全球五大核心 ETF 即時報價與多空信號：`VT` (全球全市場)、`VOO` (標普 500)、`QQQ` (科技龍頭)、`0050` (台灣龍頭)、`BND` (綜合公債)。
5. **個人化智慧投資建議引擎**：
   - 根據扣除房貸/固定開銷後的「月真實自由現金流」，結合全球市場位階，給予具體定期定額提撥金額與股債分配指引。
6. **拿鐵效應與定期定額複利試算**：
   - 具體展示省下的生活小錢投入指數化投資 20 年後的翻倍倍數。

## 🚀 快速啟動 (Local Development)

```bash

npm install

# 啟動開發伺服器
npm run dev

# 訪問網址
http://localhost:3000
```

## ☁️ 一鍵部署至雲端 (Deploy to Vercel)

本專案完全基於標準 Next.js 14 App Router 開發，可 100% 免費部署於 [Vercel](https://vercel.com)：

### 方式一：透過 Vercel 網頁介面 (推薦)
1. 將專案代碼推送到您的 GitHub / GitLab 倉庫。
2. 登入 [Vercel](https://vercel.com) 並點擊 **"Add New Project"**。
3. 選擇您的專案倉庫，Vercel 將自動識別 Next.js 並自動完成建置。
4. 點擊 **Deploy**，約 1 分鐘即可獲得永久免費的 `https://your-wealthpilot.vercel.app` 專屬網址！

### 方式二：透過 Vercel CLI
```bash
npx vercel
```
依提示登入即可完成部署。
